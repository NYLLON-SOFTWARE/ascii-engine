# Visual study references

These five JPEG frames were extracted from the user-supplied `media.mp4`, showing Ansenjeo's game. They retain their source attribution and are included as visual study references for the development comparison panel. They are not original ASCII Engine artwork and are not used as world textures.

Source creator: [Ansenjeo](https://x.com/Ansenjeo). Supplied video dimensions: **2304 × 1440**. Individual source-post metadata was not embedded in the supplied clip.

| Frame | Timestamp | What it establishes |

| `frame-5.jpg` | 00:05 | Rider/horse silhouette, fine actor glyphs, scenery scale and grass strokes |
| `frame-14.jpg` | 00:14 | Symbol map, river/road distinction, markers and interface framing |
